# 🚀 Deploy Guide — Cloudflare Pages + Workers (বাংলা)

> এই গাইডে ধাপে ধাপে: GitHub → Cloudflare Pages (frontend), Worker (API), Resend (email),
> Supabase / Neon / D1 (database), Workers AI, আর free tier-এ কী কী ফ্রি — সব আছে।

---

## 0) কী কী জিনিস আছে (এই repo-তে)

| ফাইল | কাজ |
|---|---|
| `index.html` + ১৩টি ভাষার পেজ | সাইট (GitHub Pages-এও চলবে, Cloudflare Pages-এ আরও ভালো) |
| `_headers` | CSP, cache, security headers — Cloudflare Pages অটো পড়ে |
| `_redirects` | পুরোনো/ভুল URL → সঠিক পেজ, alias |
| `functions/share.js` | Cloudflare Pages Function: ছোট OG পেজ বানায় (WhatsApp/LinkedIn preview ঠিক করার জন্য) |
| `worker/src/index.js` | Worker API: contact, CV request, review, /api/ai |
| `worker/wrangler.toml` | Worker config (RATE_KV, D1, AI binding — যেটা চান uncomment) |
| `i18n.js`, `i18n/*.json` | ১৩ ভাষার ট্রান্সলেশন ইঞ্জিন (এখন দ্রুত + race-safe) |
| `assets-fallback.js` | ছবি লোড না হলে inline WebP fallback (৩৬৪ KB → ২২৫ KB করা হয়েছে) |

## 1) Frontend → Cloudflare Pages (ফ্রি)

1. Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git**
2. আপনার repo `Mithun-Mutsuddi/Mithun-Mutsuddi.github.io` সিলেক্ট করুন
3. Build settings:
   - **Framework preset:** `None`
   - **Build command:** *(ফাঁকা রাখুন)*
   - **Build output directory:** `/` (repo root)
4. **Save and Deploy** → প্রায় ৩০ সেকেন্ডে `mithun-mutsuddi.pages.dev` লাইভ।
5. পরে কাস্টম ডোমেইন (যেমন `mithunmutsuddi.com`) যোগ করলে:
   - Pages → Custom domains → Set up a domain
   - তারপর `_redirects` ফাইলের উপরের দিকে থাকা gitHub.io → custom domain লাইনটা uncomment করুন
   - `canonical`, `og:url`, `sitemap.xml`-এ পুরোনো ডোমেইন থাকলে find-replace করুন

> **কেন GitHub Pages এর পাশাপাশি?** GitHub Pages কাস্টম হেডার (CSP/cache) দিতে পারে না,
> 167 KB HTML-কে compression/edge-cache-এ ভালোভাবে serve করে না। Cloudflare Pages
> ফ্রি-তেই Brotli + global CDN + proper cache headers দেয় → mobile-এ noticeable দ্রুত।

## 2) Backend → Cloudflare Worker (ফ্রি: দিনে ১,০০,০০০ রিকোয়েস্ট)

```bash
npm install                       # wrangler install
npx wrangler login                # ব্রাউজারে Cloudflare লগইন

cd worker
npx wrangler deploy               # প্রথম deploy → URL পাবেন:
# https://mithun-portfolio-api.<your-subdomain>.workers.dev
```

তারপর `worker/wrangler.toml`-এ যেটা দরকার uncomment করুন (নিচে ধাপে ধাপে)।

### Secrets সেট করা

```bash
npx wrangler secret put RESEND_API_KEY        # Resend API key
npx wrangler secret put OWNER_EMAIL           # mithuncacc96@gmail.com
npx wrangler secret put FROM_EMAIL            # "Mithun Portfolio <portfolio@yourdomain.com>"
```

### টেস্ট

```bash
curl https://mithun-portfolio-api.<you>.workers.dev/api/health
# → {"ok":true,"email":true,"db":"supabase",...}
```

### ফ্রন্টএন্ডে API বসানো

`index.html`-এ:

```js
var API_BASE = "https://mithun-portfolio-api.<you>.workers.dev";
```

এটা খালি (`""`) থাকলে ফর্মগুলো আগের মতোই mailto/WhatsApp খুলবে — অর্থাৎ কিছুই ভাঙবে না।

## 3) Email → Resend (ফ্রি: মাসে ৩,০০০ মেইল, দিনে ১০০)

1. [resend.com](https://resend.com) → Sign up (GitHub দিয়ে)
2. **Domains → Add Domain** → DNS records (MX, SPF, DKIM) Cloudflare DNS-এ বসান
   *(ডোমেইন না থাকলে `onboarding@resend.dev` দিয়েও টেস্ট করা যায় — শুধু নিজের ইমেইলে যাবে)*
3. **API Keys → Create** → `re_...` key কপি করুন
4. `wrangler secret put RESEND_API_KEY` → paste

কোন ফর্ম কী করে:

| ফর্ম | Worker route | কী হয় |
|---|---|---|
| Send a Message | `POST /api/contact` | আপনার Gmail-এ মেইল (Reply-To = ভিজিটরের ইমেইল) |
| Request Full CV | `POST /api/cv-request` | আপনার Gmail-এ মেইল |
| Star rating | `POST /api/review` | DB-তে pending + আপনার মেইলে নোটিফিকেশন, WhatsApp flow আগের মতোই থাকছে |

## 4) Database — কোনটা বেছে নেবেন? (তুলনা)

| | **Supabase** ✅ (রেকমেন্ডেড) | **Cloudflare D1** | **Neon** |
|---|---|---|---|
| Free tier | 500 MB DB, 1 GB storage, 50k MAU auth | 5 GB, 5M rows read/দিন | 0.5 GB storage, suspend after 5 min idle |
| Worker থেকে access | REST (fetch, 0 dependency) | বাইন্ডিং (সবচেয়ে দ্রুত) | HTTP driver / `@neondatabase/serverless` |
| বাড়তি সুবিধা | Auth, Storage, Dashboard, Row Level Security | কোনো এক্সট্রা অ্যাকাউন্ট লাগে না | Postgres-এর সব ফিচার |
| এই repo-তে | `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` | `[[d1_databases]]` uncomment + migrate | `DATABASE_URL` |

### Supabase সেটআপ (ধাপে ধাপে)

1. [supabase.com](https://supabase.com) → New project (free)
2. **SQL Editor** → চালান:

```sql
create table if not exists reviews (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) <= 80),
  company text check (char_length(company) <= 100),
  rating int not null check (rating between 1 and 5),
  comment text not null check (char_length(comment) <= 600),
  lang text default 'en',
  ip_hash text,
  approved boolean not null default false,
  created_at timestamptz not null default now()
);
alter table reviews enable row level security;

-- পাবলিক শুধু approved রিভিউ পড়তে পারবে
create policy "public read approved" on reviews
  for select using (approved = true);
-- service role key দিয়ে Worker insert করবে (RLS bypass), তাই insert policy লাগবে না
```

3. **Project Settings → API** → `Project URL` + `service_role` key
4. ```bash
   npx wrangler secret put SUPABASE_URL
   npx wrangler secret put SUPABASE_SERVICE_ROLE_KEY
   ```
5. রিভিউ approve করতে: Supabase Table Editor → reviews → `approved` = true

> ⚠️ `service_role` key কখনো ফ্রন্টএন্ডে দেবেন না — শুধু Worker secret।

### D1 চাইলে

```bash
npx wrangler d1 create mithun_portfolio        # output → wrangler.toml-এ database_id
npx wrangler d1 execute mithun_portfolio --command "CREATE TABLE reviews (
  id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, company TEXT,
  rating INTEGER NOT NULL, comment TEXT NOT NULL, lang TEXT, ip_hash TEXT,
  approved INTEGER NOT NULL DEFAULT 0, created_at TEXT DEFAULT (datetime('now')))"
```

`wrangler.toml`-এ `[[d1_databases]]` uncomment করুন।

## 5) AI → Cloudflare Workers AI (ফ্রি: দিনে ১০,০০০ neurons)

`index.html`-এ "Gemini flash lite"-এর বদলে **Workers AI** কেন?

- আলাদা API key লাগে না, billing লাগে না — Worker binding, ফ্রি tier আছে
- দ্রুত (edge-এ চলে), আর portfolio-র মতো ছোট কাজে যথেষ্ট ভালো (`llama-3.1-8b-instruct`)
- Gemini flash-lite ও ব্যবহার করা যাবে, কিন্তু তখন Google AI Studio key + `generativelanguage.googleapis.com` CSP-তে allow করতে হবে

চালু করতে `worker/wrangler.toml`-এ uncomment:

```toml
[ai]
binding = "AI"
```

তারপর `POST /api/ai` → `{"q": "ERP experience?"}` → `{"ok":true,"answer":"..."}`

> ⚠️ AI endpoint পাবলিক হলে rate limit আছে (৫/মিনিট/IP) — তবু sensitive কনটেন্টের জন্য নয়।

## 6) बोनस: Oracle Cloud Free Tier (VM) — দরকার আছে কি?

**সংক্ষেপে: আপনার সাইটের জন্য দরকার নেই।** কারণ:

| | Cloudflare Workers | Oracle Cloud Always Free VM |
|---|---|---|
| খরচ | ০ (১,০০,০০০ req/দিন) | ০ (AMD ১ GB / ARM ৪ core ২৪ GB RAM) |
| অপারেটিং overhead | নেই — deploy করলেই শেষ | OS patch, Nginx, TLS renew, firewall, monitoring — সব নিজে |
| ঠান্ডা শুরু | ~০ ms | VM sleep/reboot হলে downtime |
| DDoS | inherent | নিজে সামলাতে হবে |
| ডাটাবেস | Supabase/D1 (managed) | নিজে Postgres চালাতে হবে = ব্যাকআপের দায়িত্ব নিজের |

**কখন Oracle VM লাগতে পারে:** যদি নিজের Mail server, Selenium/Playwright scraper, `n8n`/`Odoo`
হোস্ট করতে চান, বা ২৪/৭ Python worker চালাতে চান। সেক্ষেত্রে: ARM A1.Flex (৪ OCPU, ২৪ GB)
নিন, Ubuntu 22.04, Caddy/Nginx + Let's Encrypt — আর Worker থেকে `fetch()` দিয়ে সেটাকে কল করুন।

## 7) Cloudflare Pages + Workers AI + Supabase — ফ্রি লিমিট এক নজরে (২০২৬)

| পরিষেবা | ফ্রি |
|---|---|
| Cloudflare Pages | ৫০০ build/মাস, unlimited requests, unlimited bandwidth |
| Cloudflare Workers | ১,০০,০০০ req/দিন, ১০ ms CPU/req |
| Workers AI | ~১০,০০০ neurons/দিন (llama-3.1-8b ~২০০-৩০০/day) |
| KV (rate limit) | ১,০০,০০০ read + ১,০০০ write/দিন |
| D1 | ৫ GB, ৫M row read/দিন |
| Supabase | ৫০০ MB DB, project ১ সপ্তাহ inactive থাকলে pause |
| Resend | ৩,০০০ ইমেইল/মাস, ১০০/দিন |
| GitHub Pages | ১ GB সাইট, ১০০ GB/মাস bandwidth (বিকল্প হিসেবে চলবে) |

## 9) ট্রাবলশুটিং

| সমস্যা | কারণ | সমাধান |
|---|---|---|
| ফর্মে "API error" | `API_BASE` ভুল / worker deploy হয়নি | `/api/health` ব্রাউজারে খুলে দেখুন |
| 429 rate limited | ৫ req/মিনিট | অপেক্ষা করুন, বা `RATE_LIMIT` বাড়ান |
| মেইল যায় না | Resend domain verify হয়নি | `onboarding@resend.dev` দিয়ে টেস্ট করুন |
| CORS error | origin allowlist | `ALLOWED_ORIGINS`-এ আপনার ডোমেইন যোগ করুন |
| ছবি দেখা যায় না | পুরোনো ক্যাশ | hard reload (Ctrl+Shift+R) |
| ভাষা বদলায় না | `i18n/*.json` 404 | Network tab-এ দেখুন, `_headers` deploy হয়েছে কি |
